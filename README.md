# cricket_statistics

A simple bash script that allows someone to get statistics directly from cricbuzz about players, teams, and all time records.

## The Problem

I am a cricket fan and the website, Cricinfo, has many tables that are pretty difficult to access as well as slow with many entries. Whenever I have tried to access statistics, it is simply too slow to load. Thus, this tool will enable someone to load statistics directly into one's computer, locally saving some stats.
